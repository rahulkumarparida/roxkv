# RoxKV - Lightweight Key Value Store

Hello there! 👋

Welcome to RoxKV, a lightweight key-value database written in Go by Rahul Kumar Parida.

RoxKV started as a learning project to understand how databases, storage engines, parsers, persistence layers, background workers, and concurrency work under the hood. Over time it has evolved into a small but capable key-value store with support for persistence, expiration, logging, and custom command parsing.

## Current Features

• Store key-value pairs in memory

• Optional TTL (Time To Live) support

```
  set token abc123 --ttl 30 min
```

• Automatic expiry worker that removes expired keys

• Persistent storage using daily snapshot files

• Load snapshots from oldest to newest, ensuring the latest values overwrite older ones

• Command history and logging system

• Filter logs using:

```
  history
  history --success
  history --error
```

• Custom parser supporting:

```
  "double quotes"
  'single quotes'
  `backticks`
```

• Thread-safe storage using read-write mutexes
