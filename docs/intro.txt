# RoxKV - Lightweight Networked Key-Value Database

Hello there! 👋

Welcome to **RoxKV**, a lightweight networked key-value database written entirely in Go by **Rahul Kumar Parida**.

RoxKV began as a personal challenge to understand how systems like Redis work internally—not by reading about them, but by building one from scratch.

What started as a simple in-memory map has gradually evolved into a small database server featuring persistence, TTL expiration, custom command parsing, background workers, TCP networking, concurrent client handling, and a Publish/Subscribe messaging system.

The goal of this project is not to replace Redis, but to explore the engineering behind storage engines, networking, concurrency, synchronization, and distributed system concepts one feature at a time.

---

## Current Features

### Storage Engine

* In-memory key-value storage
* Binary-safe value storage using []byte
* Compatible with redis-py, django-redis, and arbitrary binary payloads
* Thread-safe operations using `sync.RWMutex`
* Shared storage across multiple TCP clients

### Persistence

* Daily snapshot-based persistence
* Restore snapshots from oldest to newest
* Latest values automatically overwrite stale data

### Time To Live (TTL)

* Optional key expiration

```text
set token abc123 --ttl 30 min
```

* Background expiry worker
* Automatic cleanup of expired keys

### Networking

* Raw TCP server
* Multi-client support
* Concurrent request handling
* Connection inactivity worker
* Configurable maximum client limit

Connect using:

```text
nc localhost 6969
```

### Publish / Subscribe

* Subscribe to topics
* Publish messages
* Unsubscribe from topics
* List active topics
* Close topics

Example:

```text
Subscribe game

Publish game GTA6

Unsubscribe game

Topics

CloseChannel game
```

### Logging & History

View complete history:

```text
history
```

Filter logs:

```text
history --success

history --error

history --info
```

### Custom Command Parser

Supports quoted and unquoted values.

```text
set name Rahul

set game "Battlefield 4"

set quote 'Never Stop Learning'

set desc `Testing Build`
```

The parser was implemented manually and preserves spaces inside quoted strings.

## Why RoxKV?

RoxKV exists to answer questions like:

* How does Redis communicate over TCP?
* How are storage engines designed?
* How does a parser understand commands?
* How do goroutines coordinate safely?
* How are TTL workers implemented?
* How does Pub/Sub messaging actually work?
* How do multiple clients share the same in-memory database?

Every feature is implemented with the goal of understanding **why** it works, not just making it work.
