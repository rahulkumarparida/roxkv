NAME
roxkv - lightweight networked in-memory key-value database with
persistence, TTL support, Pub/Sub messaging, and history logging.

SYNOPSIS
set <key> <value...>
set <key> <value...> --ttl <number> <sec|min|hr>

```
   get <key>

   del <key>

   save

   load

   keys

   history
   history --success
   history --error
   history --info

   Subscribe <topic>

   Publish <topic> <message>

   Unsubscribe <topic>

   Topics

   CloseChannel <topic>
```

DESCRIPTION
RoxKV is a lightweight networked key-value database written in Go.
It was built from scratch as an educational project to explore the
internal design of systems like Redis.

```
   Data is stored entirely in memory for fast access and may be
   persisted to disk using snapshot files. RoxKV also provides
   automatic key expiration, structured logging, a background expiry
   worker, and a TCP server allowing multiple concurrent clients to
   interact with the same shared database.

   In addition to key-value storage, RoxKV implements a lightweight
   Publish/Subscribe messaging system for real-time communication
   between connected clients.
```

COMMANDS

```
   set <key> <value...>
          Creates a new key or updates an existing key.

          Values may span multiple words and may be enclosed in
          single quotes (' '), double quotes (" "), or backticks (` `)
          to preserve spaces.

          Examples:
              set username rahul
              set game "Battlefield 4"
              set quote 'Never Stop Learning'


   set <key> <value...> --ttl <number> <sec|min|hr>
          Stores a key with an expiration timestamp.

          After the specified duration expires, the background worker
          automatically removes the key from memory.

          Supported units:

              sec     Seconds
              min     Minutes
              hr      Hours

          Examples:

              set otp 1234 --ttl 30 sec
              set session abc123 --ttl 10 min
              set cache data --ttl 2 hr


   get <key>
          Retrieves the value associated with the supplied key.

          If the key does not exist, nil is returned. If the key has
          already expired, it is deleted immediately before returning.

          Examples:

              get username
              get game


   del <key>
          Removes a key from the database.

          If the key is not present, an informational message is
          written to the history log.

          Examples:

              del username
              del otp


   save
          Writes the current in-memory dataset to disk.

          RoxKV stores snapshots using date-based files while
          preserving previously saved data.

          Examples:

              save


   load
          Restores previously saved snapshots into memory.

          Snapshots are processed from oldest to newest so that newer
          values automatically replace older versions of the same key.

          Examples:

              load


   keys
          Lists every key currently stored in memory.

          Useful for verifying inserts, deletions and successful
          snapshot loading.

          Examples:

              keys


   history
          Displays every recorded log entry.

          Includes successful operations, informational events and
          runtime errors.

          Examples:

              history


   history --success
          Displays only successful operations.

          Examples:

              history --success


   history --error
          Displays only error entries.

          Useful when debugging command parsing, persistence or server
          related failures.

          Examples:

              history --error


   history --info
          Displays informational log entries.

          Includes events such as key deletion, loading, expiration
          and other runtime notifications.

          Examples:

              history --info


   Subscribe <topic>
          Creates a topic if it does not already exist and subscribes
          the current TCP client to it.

          Messages published to the topic are immediately delivered to
          every connected subscriber.

          Examples:

              Subscribe game
              Subscribe notifications


   Publish <topic> <message>
          Broadcasts a message to every client subscribed to the
          specified topic.

          Only authorized publishers for a topic may publish
          messages.

          Examples:

              Publish game GTA6
              Publish chat "Hello Everyone"


   Unsubscribe <topic>
          Removes the current client from a subscribed topic.

          After unsubscribing, future publications to that topic are
          no longer delivered to the client.

          Examples:

              Unsubscribe game


   Topics
          Lists every active Pub/Sub topic currently managed by the
          server.

          Examples:

              Topics


   CloseChannel <topic>
          Permanently removes a topic and disconnects every publisher
          and subscriber associated with it.

          Examples:

              CloseChannel game
```

FILES

```
   ~/.roxkv/roxdb/
          Contains persisted snapshot files.

   ~/.roxkv/roxlogs/
          Contains daily log files.

   ~/.roxkv/docs/
          Contains bundled documentation and manual pages.
```

BACKGROUND SERVICES

```
   Expiry Worker
          Periodically scans every stored key for expired TTL values
          and removes expired entries automatically.

   Connection Worker
          Monitors connected TCP clients and automatically disconnects
          inactive connections after the configured timeout period.
```

NETWORKING

```
   RoxKV exposes a raw TCP server.

          Default Address:

              localhost:6969

          Connect using:

              nc localhost 6969
```
